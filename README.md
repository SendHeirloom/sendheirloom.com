# Heirloom Website

This is the marketing site hosted at sendheirloom.com, not including the ordering website.

### Technologies used:

- [Netlify CMS](https://www.netlifycms.org/)
- [Eleventy](https://www.11ty.dev/)

## Getting Started

### 1\. Clone this Repository

```
git clone https://github.com/sendheirloom/sendheirloom.com
```

### 2\. Navigate to the directory

```
cd sendheirloom.com
```

### 3\. Install dependencies

```
yarn install
```

### 4\. Build the project to generate the first CSS

This step is only required the very first time.

```
yarn run build
```

### 5\. Run Eleventy

```
yarn run start
```
